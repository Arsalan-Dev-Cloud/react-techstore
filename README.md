# React TechStore

A complete React landing page example built with Vite.

## Features

- Reusable React components
- Props
- useState
- useMemo
- Product search
- Category filtering
- Cart counter
- Newsletter form
- Responsive navigation
- Responsive CSS
- Product rendering with map()

## Run the project

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.
